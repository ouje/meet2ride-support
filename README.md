# Meet2Ride Support

This repository is used only for bug reports, feature requests, and user feedback for the Meet2Ride app.

The application source code is private and is not stored in this repository.

## Report a problem or suggest a feature

Please use GitHub Issues:

https://github.com/ouje/meet2ride-support/issues/new/choose

## Translations

Meet2Ride can add support for more languages based on user demand and available help.

If you want a new language, or if you can help translate the app, open a **Translation** issue:

https://github.com/ouje/meet2ride-support/issues/new?template=translation.yml

Please include:

- the language you want or can translate
- whether you are a native or fluent speaker
- how you can help, if you want to contribute translations

The app source code is private, so translations cannot be submitted as a pull request here. The Meet2Ride team will review requests and contact contributors when translation work is needed.

## Important

Please do not post personal data, API keys, screenshots with private information, or security-sensitive details.
